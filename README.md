# Profile Page

A simple React profile page that showcases a student name, learning goal, and work status badge.

## Description

This project was built as a profile page for a course assignment. It includes a heading, a short personal goal, and a status pill that changes between "Open to work" and "Busy learning" using a ternary expression.

## Setup

1. Open the project folder.
2. Run `npm install`.
3. Start the app with `npm run dev`.
4. Visit the local Vite URL in your browser.
